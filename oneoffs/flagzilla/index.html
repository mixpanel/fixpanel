    Verifier

    —

    Checks every flag served to the active persona against the manifest's expect. Percent rollouts get no per-user verdict; the sweep checks them in aggregate.

    Mismatches

    How each kind is checked
    • deterministic: served, with the expected variant. Configs also need variant_value._fz to equal the flag key.
    • test-users: a listed QA user gets the pinned variant. Everyone else gets nothing.
    • rule: the first group whose rule matches the persona gives the variant. No match means absent. A Date condition matches only an RFC3339 runtime value, as the flags docs state. The app sends signup_ts as RFC3339 unless the persona panel says epoch ms; then those conditions never match.
    • rule-percent: no rule match means absent. A match is checked in aggregate by the sweep.
    • percent: 0% means absent, 100% means served. Other levels are checked in aggregate.
    • cohort: the profile property decides. A mismatch on a project under a day old reads "possible sync lag".
    • first-event: absent before the trigger event, On after it. The first-event panel tests the flip.
